第 6 组 HUD · 小组件主题套件

从 group6-hud.html 的 10 屏 Game HUD 里抽出一套可复用的小组件主题：荧光绿主数据、琥珀告警、青色副序列，四角括号、等宽数字、分段条与刻度环。 选型不按组件名拍脑袋，而是按数据类型与可用形状决定：布尔→灯，有界百分比→环/条/柱，无界标量→大数字，单序列→折线，双序列→双折线，文本→徽章。 所有尺寸按小组件 2.0 的 26.667px 网格 1:1 绘制，元素仅使用 LVGL 9.3 可实现的纯色/渐变、描边、圆角、圆弧、分段条、折线、LED 与透明度动画。

04 组件标本 1:1 · 26.667px GRID · PORTRAIT

每张卡片展示同一数据类型在不同尺寸下的形态变化。左侧标签是组件类型，右下角是真实网格尺寸与像素；所有数值、单位、标签均按 8/10/13/16/22/30px 字阶。

05 尺寸密度规则 SMALL → LARGE

尺寸变大不是等比放大，而是逐级增加信息：小尺寸只保留编码，大尺寸才补刻度、阈值、单位和脚注。低于 60px 高的组件不画标题栏。

07 落地清单 THEME TOKENS + LVGL

先写入 shared/catalog/themes.json，再让 ui_mini.c 读取同一组 token；Web 编辑器按 token 注入 CSS 变量。新增皮肤时同步补 app.js / style.css 的 skin 分支。

{
  "id": "hud-tactical",
  "label": "战术 HUD",
  "description": "军绿黑底 + 荧光绿主数据 / 琥珀告警 / 青色副序列，四角括号与分段条",
  "tokens": {
    "bg": "#0A0F0C",          "surface": "#12201A",     "surface_2": "#0A120E",
    "border": "#27402D",      "text": "#D8F5D0",        "text_dim": "#6D8673",
    "text_mut": "#3E5740",    "accent": "#7CFF4F",      "accent_2": "#FFB020",
    "cyan": "#3BE0C0",        "ok": "#7CFF4F",          "warn": "#FFB020",
    "err": "#FF5347",         "pink": "#FF78A0",        "radius": 2,
    "skin": "hud-tactical",   "surface_grad_from": "#12201A", "surface_grad_to": "#0A120E",
    "glow": "#7CFF4F",       "glow_opa": 0,           "border_width": 1,
    "corner_len": 9,          "font_style": "mono",        "tracking": 1,
    "deco": "corners",        "pet_variant": "hud-drone"
  }
}
  • 数值字体：一律等宽（Montserrat 数字仍可用，但小数/单位分开排版）；标签 8–9px，正文 10–12px，数值 13–24px，hero 30–60px。
  • 分段条：用 lv_obj 自绘 N 段，段数按宽度取 clamp(w/10, 6, 32)，禁止用 lv_bar 的连续填充冒充弹药条。
  • 角括号：4 个 9×9 的 1px 描边 lv_obj（或 lv_line），只描两条边；不要做整卡圆角 + 阴影。
  • 刻度：lv_line 每 10° 一条，主刻度不透明度 0.6，次刻度 0.25；刻度环旋转仅在外层，18s/圈。
  • 动效预算：LED 呼吸 2.2s，扫描扇 6s，数值用 300ms lv_anim；SPI 屏默认关闭旋转与全屏重绘，只失效组件局部。
  • 阈值着色：未越线用 accent，越过 warn_above 用 accent_2，越过 danger_above 用 err；颜色变化只作用于进度与数值，不改变卡片底色。
  • 空值：指标不可用时数值显示 --，灯变 text_mut 并停止呼吸，禁止显示 0 造成误判。
  • Web 对齐：编辑器的 mini_ratio / mini_value_color 必须与固件同口径；新主题的 skin 覆盖写在 #canvas[data-theme="hud-tactical"] 下。
  • 皮肤枚举：skin_from_name() 目前只认 4 套，未知值会静默回退 UI_SKIN_NEON。新增 HUD 必须在 ui.h 加 UI_SKIN_HUD、在 ui_dynamic.c 加映射、并在 ui_mini.c 补分支；只改 themes.json 只会换色，不会换形态。
  • 桌宠：pet_variant: "hud-drone" 未实现前会回退 cyber-cat；要无人机造型需在 ui_pet.c 新增分支。
