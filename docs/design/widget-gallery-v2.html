尺寸：从 2×2 到 6×6，不止正方形

竖屏 12×18 网格、单元格 18.67px、间距 8px。正方规格覆盖 2×2 → 6×6； 另配 12×2 / 12×3 / 12×4 长条、2×4 / 2×6 竖条、4×3 / 8×6 横竖矩形。 卡片高度不足 60px 时自动省略标题栏，把整格留给图形。

形态：同一组件按宽高比换布局

  • bar_strip 按高度 2 / 3 / 4 切换 inline / 堆叠 / hero
  • led_matrix 单元格偏高堆叠、偏宽横排
  • gauge_ring 紧凑模式丢掉刻度与单位

数值：量程与阈值统一口径

  • 量程：max_value → %/°C 归 100 → v/(v+1) 软缩放
  • 越 warn 线转琥珀、越 danger 线转红
  • 极值柱用第二主色高亮，一眼定位瓶颈

动效：只在有含义处动

  • 在线呼吸 1s 正弦，离线 1Hz 硬闪
  • dual_line 主线面积填充 20% 透明度
